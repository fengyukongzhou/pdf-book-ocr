# Subagent OCR Prompt Templates (Low-Token & High-Fidelity)

针对不同类型的书籍，启动 `ocr_specialist` 并发转写子智能体时，使用以下经过实证检验的精炼提示词模板，确保子智能体直接在独立上下文中将结果落盘到指定 Markdown 路径，仅向主智能体汇报极简状态（字符数与页数），从而**最大限度节约父对话的 Token 消耗**。

---

## 0. 数字文字版分片语义重构与清洗 (Digital Text Restructuring)

针对 `subagent_jobs.json` 中 `is_digital: true` 的切片任务，已预提取原始文本层和插图标记到 `{raw_text_path}`。子智能体应直接基于该草稿进行出版级排版与语义重构，彻底剥离页码与硬折行：

```text
请使用 view_file 查看分片原始文本草稿：
`{raw_text_path}`
（已完整包含原生文本与抽取好的插图标记）

【工具使用铁律与信息封闭原则】：
- 本任务**只允许且必须仅使用 `view_file` 读取草稿与 `write_to_file` 写入文件**，严禁调用其他任何工具。
- **绝对禁止调用 `search_web` 或进行任何外部联网检索**。当前分片文本为唯一权威数据源，即使遇到看不懂的特殊词汇或前卫数字，也必须忠实原样保留，严禁擅自去外网考证或“修正”译文！
- **严禁调用 `run_command` 编写脚本**探测底层坐标或测量文字。

请执行出版级高精度语义清洗与排版重构，直接处理文本并写入目标文件：
1. 【彻底剥离印刷流水杂音】：彻底删除所有独立成行的印刷流水页码（例如孤立一行的纯数字如 51、64、65、71 等）以及页眉眉心书名。
2. 【段落硬换行缝合】：自动缝合因页面排版折行产生的断句，同一个自然段落必须合并为连贯的一整段。段落之间必须留且仅留一个空行。严禁在行末添加双空格造成软换行。
3. 【配图规范】：严格保留文本中已有的配图标记。若原书插图没有明确的图题说明，alt 文本必须保持为空 `![](images/fig_...)`，**严禁写多余的“插图”二字**；只有原书印有明确图题时，才填写 `![图题](images/fig_...)`。
4. 【随文注 vs 脚注铁律】：必须 100% 忠实原文版式结构！
   - **随文括号注/夹注**：原书中凡是写在段落内部或段落末尾的括号注释（如“（注：……”、“（译者按：……”），**必须原样保留在正文中**，绝对禁止擅自将其剥离并改造成 `[^n]` 跳转脚注！
   - **页面真正脚注**：仅当原书版心下方印有真正的数字角标底注时，才在正文使用 `[^p{part_index}_1]` 并于文末以 `[^p{part_index}_1]: 内容` 呈现。
   - 严禁擅自补充个人解释或伪造任何脚注。
5. 【剔除版权与推广信息】：文前与文后的版权页、出版声明、图书在版编目（CIP）、发行机构、公众号/二维码推广等信息直接丢弃，不写入 Markdown。
6. 【体裁保真】：保留原文中的加粗、斜体与标题格式（篇目大标题格式化为 ##）。
7. 重构完成后，使用 write_to_file 将完整 Markdown 直接保存到：
`{out_slice_md_path}`
8. 完成后仅汇报：重构完成状态与总字数。
```

## 1. 散文 / 小说 / 非虚构通识类 (Prose & General Non-Fiction)

```text
请使用 view_file 查看 PDF 分片文件：
`{slice_pdf_path}`（共 {page_count} 页）

请仔细阅读每一页的页面截图，进行逐字逐句的高精度数字化转写：
1. 完整识别正文，严禁遗漏、跳过、概括或缩写任何文字。
2. 自动缝合段落内因印刷排版产生的硬换行，自然段落之间必须留且仅留一个空行。严禁在行末添加双空格造成软换行。
3. 彻底剔除印刷版顶部的书脊眉心标题与页底印刷流水页码。
4. 【注释原则】：仅当页面底端存在真正的带标号脚注/尾注时，才在正文标注标准 Markdown 脚注 [^p{part_index}_1], [^p{part_index}_2]... 并在文末统一列出。若原书注释为段落内的随文括号注（如“（注：……”），必须原样保留在正文内，严禁擅自转为脚注！
5. 若页面包含插图、照片或图表，请在相应段落之间标注：
   <!-- FIGURE: page={切片内第几页从1起} bbox=[ymin, xmin, ymax, xmax] -->
   ![{图题}](images/part_{part_index}_fig_{fig_index}.png)
   *{图题说明}*
   （注意：若原书没有图题，alt 文本请保持为空 ![](images/...)，严禁填写多余的“插图”二字；bbox 为 0~1000 归一化坐标 [上, 左, 下, 右]，仅严格框选图形/画面本身，绝对严禁框入下方的正文文字、作者简介、图注文字或页面字迹，防止正文出现文字重复）
6. 【剔除版权与推广】：文前与文后的版权页、出版声明、CIP 编目、发行机构、公众号/二维码推广等信息直接丢弃，不写入 Markdown。
7. 转写完成后，将完整 Markdown 直接保存到：
`{out_slice_md_path}`
8. 完成后仅汇报：转写完成状态与总字数。
```

## 2. 戏剧 / 剧本类 (Drama & Screenplays)

```text
请使用 view_file 查看 PDF 戏剧分片文件：
`{slice_pdf_path}`（共 {page_count} 页）

请仔细阅读每一页的页面截图，按以下严苛规范进行逐字逐句转写：
1. 【对白分段铁律】：每一位角色的台词必须独立成段！行末严禁使用双空格软换行（  \n）。不同角色的台词之间必须使用空行分隔（\n\n）。
2. 【角色姓名格式】：发言人姓名必须加粗独立呈现，例如 `**角色名**：台词内容`。
3. 【舞台指示与动作】：人物上下场、道具动作与情态描写一律使用独立斜体段落，如 `*此时钟声响起。*`，前后必须各留一个空行。
4. 【和歌与诗歌童谣】：百鬼夜行曲、民谣童谣等使用独立引用块（> 诗句），诗句内部换行可使用行尾双空格。
5. 【开篇人物表规范】：人物表如存在，必须在 `**登场人物**：` 标题下方空出一整行，再使用 `- **角色**，描述` 列表格式。
6. 【注释原则】：仅当存在真正的页底脚注时，才标注为 [^p{part_index}_1]... 并在文末列出；正文内的随文说明与括号注一律原样保留在对白/正文中。
7. 若页面包含剧照、舞台平面图或插图，在段落间标注：<!-- FIGURE: page={切片内第几页从1起} bbox=[ymin, xmin, ymax, xmax] --> 紧跟一行 ![{图题}](images/part_{part_index}_fig_{fig_index}.png) 与一行 *{图题说明}*。（若无图题说明，alt 文本留空 `![](...)`，切勿写“插图”二字）。
8. 【剔除版权与推广】：文前与文后的版权页、出版声明、推广信息直接丢弃，不写入 Markdown。
9. 转写完成后，将结果直接保存到：
`{out_slice_md_path}`
10. 完成后仅汇报：转写完成状态与总字数。
```

## 3. 学术著作 / 稠密注释专著 (Academic & Dense Footnotes)

```text
请使用 view_file 查看 PDF 学术分片文件：
`{slice_pdf_path}`（共 {page_count} 页）

请仔细阅读每一页的页面截图，进行出版级高精度转写：
1. 完整识别正文与全部学术引文，严禁遗漏任何拉丁字母、引文出处或专有名词。
2. 遇有正文插表，使用标准 GitHub Flavored Markdown 语法还原表格结构。
3. 遇有正文插图、图表或地图，在相应段落间标注：
   <!-- FIGURE: page={切片内第几页从1起} bbox=[ymin, xmin, ymax, xmax] -->
   ![{图题}](images/part_{part_index}_fig_{fig_index}.png)
   *{图题说明}*
   （bbox 为 0~1000 归一化坐标，仅框选图框/数据区域，不框选底部标题文本；若无图题，alt 留空 `![](...)`，勿写多余“插图”）。
4. 专著注释通常极其密集：正文见上标处务必精准插入 [^p{part_index}_1]，引文作者、书名、版次、页码在文末务必逐条精确对应，严禁合并或丢失编号。随文括注保持原样。
5. 【剔除版权与推广】：文前与文后的版权页、出版发行、CIP 等信息直接丢弃，不写入 Markdown。
6. 转写完成后，将结果直接保存到：
`{out_slice_md_path}`
7. 完成后仅汇报：转写完成状态、总字数及识别出的脚注数量。
```
